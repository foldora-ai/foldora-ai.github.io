    How do you plan folders for hundreds of files?

    Start with a small set of categories you can explain to another person. Paste a representative filename list and choose one rule at a time. Extension rules group formats such as PDFs and images; keyword rules use words already present in the names. Compare the proposed locations with how you actually retrieve those files, then refine the rules before handling a large batch.

    For a mixed Downloads folder, separate predictable groups first: documents, photos, archives, and installers. A PDF named scan001.pdf has little context, so a format-only rule can place it under Documents but cannot tell whether it is a receipt, contract, or medical record. Keyword rules work only when a meaningful term appears in a name. Ordered rules resolve overlaps by choosing the first matching rule and flagging every conflict for review.

    Dates are used only when a filename contains one unambiguous, calendar-valid YYYY-MM-DD date. A missing, impossible, or multiple date goes to Needs review rather than an invented year. A date in a filename may still describe a download, meeting, or invoice; verify its meaning before using it as a permanent filing rule.

    Before making real changes, back up important folders, review the proposed destination of each file, check duplicate basenames and existing destination names, and move a small sample manually. This planner cannot see current folder contents or detect collisions with files already on disk. A CSV is a review checklist, not an instruction for an automated mover.

    Step-by-step workflow

    1. Paste one filename per line, or keep the built-in mixed Downloads example. The text stays in this browser tab.
    2. Choose file type, strict filename date, or keyword rules. For keywords, edit the rows and move higher-priority rules upward.
    3. Inspect the proposed tree and every before-and-after row. Treat conflicts, duplicates, and uncertain names as manual review items.
    4. Copy the folder structure or download the CSV mapping as a checklist. Create folders and move files only after verifying real originals and backups.

    Frequently asked questions

    Does the planner upload or inspect my files?

    No. You paste filename text into the page. Its rule engine runs in your browser without file, folder, account, or network access for those names. Do not paste sensitive names on a shared screen.

    Can it organize a Downloads folder automatically?

    No. It produces a text preview and CSV checklist. It cannot see your Downloads folder or perform moves, so check the actual folder before doing anything manually.

    What if a filename matches two keywords?

    The first rule in the visible rule list wins. The row is flagged as a conflict so you can change rule order or review it manually.

    How does date organization work?

    The planner accepts one real YYYY-MM-DD date in the filename. Missing, invalid, or multiple dates go to Needs review. It cannot determine whether a valid date describes the document itself.

    When is local AI more useful than filename rules?

    When names are vague and supported file contents supply the needed context, Foldora can propose folders and names from local analysis. You must inspect its suggestions before applying changes.
