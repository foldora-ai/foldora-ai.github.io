What Foldora reads and where it fits

Foldora uses filenames and available content from supported files to suggest folders and clearer names. Common supported types include PDF, DOCX, TXT, XLSX, CSV, PPT, PPTX, PNG, JPG, GIF, WEBP, and ZIP. Content analysis varies by format; a ZIP archive, for example, is not treated like a readable document. Foldora suits selected batches of mixed files rather than continuously monitored, rule-based routing. Review uncertain suggestions and keep a backup before large changes; a guaranteed one-click undo is not advertised.

How Foldora works

  1. Select a folder on your computer.
  2. Foldora analyzes supported files locally.
  3. Review proposed categories and filenames.
  4. Apply only the changes you approve.
